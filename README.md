# 더그아웃! Dugout

야구부 감독을 위한 팀 운영 앱입니다. 초·중·고 학교급을 고를 수 있습니다.

- 투구 수 기록과 등판 가능일 계산
- 라인업·수비 위치, 대회 제출 명단 인쇄
- 타석 기록, 타구 방향, 선수별 기록
- PC 경기 분석 화면
- 대회·훈련 일정과 출석인정 안내문
- 훈련 일지, 학업 체크, 장비 대여
- 학부모 공지판 (로그인 없이 QR로 보기)
- 훈련 일지 기간 골라 인쇄·PDF
- 첫 설정 도우미
- 휴대폰·PC에 앱으로 설치 (홈 화면에 추가)

## 학생 정보 보호
학생 이름·등번호·학년, 학업 메모, 결석 사유, 상대 팀 메모는 사용자의 기기에서 팀 비밀번호로 암호화(AES-GCM)한 뒤 저장합니다. 같은 이름도 저장할 때마다 다른 암호문이 되고 길이도 일정하게 채우므로, 서버에서는 운영자도 이름을 알아볼 수 없습니다.
